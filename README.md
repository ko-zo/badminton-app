# バドミントン組み合わせアプリ

バドミントンのオフ会・練習会で、参加者をランダムに組み合わせて対戦表を作成するPWAアプリです。  
スマホのホーム画面にインストールして、インターネット不要でも使えます。

## アプリURL

```
https://ko-zo.github.io/20260414_badminton-app/
```

## 機能一覧

### 登録簿
- メンバーの名前を登録・削除
- 性別（M/F）をボタンで切り替え設定（タップするたびに − → M → F → − と切り替わります）
  - 男性（M）：青背景
  - 女性（F）：ピンク背景
- 「今回参加する」スイッチで当日の参加をON/OFF

### 今回の参加者
- 参加ONのメンバーを一覧表示
- 「休憩希望」チェックで今回の抽選から除外

### 設定・実行
- **コート数**：＋/−ボタンで調整（参加人数に応じて自動制限）
- **コート別シングル/ダブルス**：コートごとに種別を個別設定（デフォルト：ダブルス）
- **組み合わせ優先**（3択）：
  - **ランダム**：完全ランダム
  - **混合優先**：男女ペアを優先（ダブルスのみ有効）
  - **同性対戦優先**：男性同士・女性同士の試合を優先

### 対戦表
- コートごとに対戦カードを表示（ダブルス：ペアvsペア / シングル：1vs1）
- プレイヤー名に性別カラーを表示
- 「もう一度シャッフル」で同じラウンドの設定のまま再抽選
- **待機**（コートに入れなかった人）・**希望休憩**を一覧表示

### 前回待機・休憩者の優先
- 前のラウンドで待機・休憩希望だったメンバーは、次のラウンドで選ばれやすくなります（3倍の重み付き）

## スマホへのインストール方法

### iPhone（Safari必須）

1. **Safari** でアプリURLを開く
2. 画面下部の**共有ボタン**（↑アイコン）をタップ
3. **「ホーム画面に追加」** をタップ
4. **「追加」** をタップして完了

### Android（Chrome）

1. **Chrome** でアプリURLを開く
2. 右上の **「⋮」メニュー** をタップ
3. **「ホーム画面に追加」** または **「アプリをインストール」** をタップ
4. **「インストール」** をタップして完了

> インストール後はホーム画面のアイコンから起動できます。  
> 一度読み込まれた後はオフライン（圏外）でも動作します。

## バージョン更新時（既にインストール済みの場合）

アプリが更新された場合、以下の手順で最新版に更新してください。

**iPhone：** ホーム画面アイコンからアプリを開き、完全に閉じてから再度開く  
**Android：** ホーム画面アイコンからアプリを開くと自動更新されます

更新されない場合はブラウザのキャッシュをクリアしてください。

## 開発者向け：ローカル環境セットアップ

### 前提条件
- Git がインストールされていること
- テキストエディタ（VSCode推奨）

### セットアップ手順

```bash
# リポジトリをクローン
git clone https://github.com/ko-zo/20260414_badminton-app.git

# フォルダを開く
cd 20260414_badminton-app
```

### 編集からデプロイまでの流れ

```bash
# ファイルを編集後、変更をコミット
git add .
git commit -m "変更内容の説明"

# GitHubへプッシュ（数分後にGitHub Pagesへ自動反映）
git push
```

### 技術スタック

| 項目 | 内容 |
|------|------|
| フロントエンド | HTML / CSS / JavaScript（バニラJS） |
| ホスティング | GitHub Pages |
| PWA | manifest.json + Service Worker |
| データ保存 | localStorage |
| 外部依存 | なし（ライブラリ不使用） |

### ファイル構成

```
├── index.html        # メイン画面
├── app.js            # アプリロジック
├── style.css         # スタイルシート
├── manifest.json     # PWA設定
├── sw.js             # Service Worker（オフライン対応）
└── icons/            # アプリアイコン
    ├── icon-192.svg
    ├── icon-512.svg
    └── icon-maskable.svg
```
