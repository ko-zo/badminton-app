# バドミントン組み合わせアプリ

バドミントンのオフ会・練習会で、参加者をランダムに組み合わせて対戦表を作成するPWAアプリです。  
スマホのホーム画面にインストールして、インターネット不要でも使えます。

## アプリURL

```
https://ko-zo.github.io/badminton-app/
```

---

## 機能一覧

画面は3つのタブに分かれています。

| タブ | 用途 |
|------|------|
| **メンバー** | 登録簿と、その日の参加者の管理 |
| **試合** | コート設定と組み合わせの作成・確定 |
| **記録** | その日の試合数、対戦履歴、過去の記録 |

### 登録簿
- メンバーの名前を登録・削除
- 性別（M/F）をボタンで切り替え設定（タップするたびに − → M → F → − と切り替わります）
  - 男性（M）：青背景
  - 女性（F）：ピンク背景
- 「今回参加する」スイッチで当日の参加をON/OFF

### 今回の参加者
- 参加ONのメンバーを一覧表示
- 「休憩希望」チェックで今回の抽選から除外

### 設定・実行
- **コート数**：＋/−ボタンで調整（参加人数に応じて自動制限）
- **コート別シングル/ダブルス**：コートごとに種別を個別設定（デフォルト：ダブルス）
- **組み合わせ優先**（3択）：
  - **ランダム**：完全ランダム
  - **混合優先**：男女ペアを優先（ダブルスのみ有効）
  - **同性対戦優先**：男性同士・女性同士の試合を優先
- 上記の設定（コート数・種別・組み合わせ優先）はアプリを閉じても保存されます

### 対戦表
- コートごとに対戦カードを表示（ダブルス：ペアvsペア / シングル：1vs1）
- プレイヤー名に性別カラーを表示
- **待機**（コートに入れなかった人）・**希望休憩**を一覧表示

### 記録のしかた（確定 / 取り消し）

組み合わせを「作った」だけでは記録されません。実際に試合をしたときだけ記録します。

| 操作 | 動作 |
|------|------|
| **組み合わせ作成** | 組み合わせを表示する（記録されない） |
| **もう一度シャッフル** | 何度でも引き直せる（記録されない） |
| **確定** | 試合をしたものとして記録に残す |
| **取り消し** | 試合をしなかったものとして破棄する |

確定か取り消しをするまで次の組み合わせは作れないので、記録の押し忘れが起きません。

### 記録タブ
- **今日の試合数**：メンバーごとの試合数。最少の人はオレンジ色で表示
- **今日の対戦履歴**：確定した対戦の一覧。間違って確定したものは削除できます
- **過去の記録**：過去の練習会の日付と試合数（直近100回分を保持）
- **書き出し**：全記録をJSONファイルとして保存

### 公平性と組み合わせの多様性

**誰が出るか**は、その日の試合数が少ない人から順に決まります（同数の人はランダム）。確率ではなく試合数で決めるため、同じ人が続けて待機し続けることがありません。

**どう組むか**は、その日すでに組んだペア・対戦した相手を避けるように選ばれます。「組み合わせ優先」を設定している場合はそちらが優先され、重複回避は同点時の判断に使われます。

集計はその日のセッションのみが対象です。日付が変わると自動的に新しいセッションが始まるため、メンバーの違う過去の練習会と混ざりません。

## スマホへのインストール方法

### iPhone（Safari必須）

1. **Safari** でアプリURLを開く
2. 画面下部の**共有ボタン**（↑アイコン）をタップ
3. **「ホーム画面に追加」** をタップ
4. **「追加」** をタップして完了

### Android（Chrome）

1. **Chrome** でアプリURLを開く
2. 右上の **「⋮」メニュー** をタップ
3. **「ホーム画面に追加」** または **「アプリをインストール」** をタップ
4. **「インストール」** をタップして完了

> インストール後はホーム画面のアイコンから起動できます。  
> 一度読み込まれた後はオフライン（圏外）でも動作します。

## バージョン更新時（既にインストール済みの場合）

アプリが更新された場合、以下の手順で最新版に更新してください。

**iPhone：** ホーム画面アイコンからアプリを開き、完全に閉じてから再度開く  
**Android：** ホーム画面アイコンからアプリを開くと自動更新されます

更新されない場合はブラウザのキャッシュをクリアしてください。

## 開発者向け：ローカル環境セットアップ

### 前提条件
- Git がインストールされていること
- テキストエディタ（VSCode推奨）

### セットアップ手順

```bash
# リポジトリをクローン
git clone https://github.com/ko-zo/badminton-app.git

# フォルダを開く
cd badminton-app
```

### 編集からデプロイまでの流れ

```bash
# ファイルを編集後、変更をコミット
git add .
git commit -m "変更内容の説明"

# GitHubへプッシュ（数分後にGitHub Pagesへ自動反映）
git push
```

### 技術スタック

| 項目 | 内容 |
|------|------|
| フロントエンド | HTML / CSS / JavaScript（バニラJS） |
| ホスティング | GitHub Pages |
| PWA | manifest.json + Service Worker |
| データ保存 | localStorage |
| 外部依存 | なし（ライブラリ不使用） |

### ファイル構成

```
├── index.html        # メイン画面
├── app.js            # アプリロジック
├── style.css         # スタイルシート
├── manifest.json     # PWA設定
├── sw.js             # Service Worker（オフライン対応）
└── icons/            # アプリアイコン
    ├── icon-192.svg
    ├── icon-512.svg
    └── icon-maskable.svg
```
