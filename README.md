# バドミントン組み合わせアプリ

バドミントンのオフ会・練習会で、参加者をランダムに組み合わせて対戦表を作成するPWAアプリです。  
スマホのホーム画面にインストールして、インターネット不要でも使えます。

## アプリURL

```
https://ko-zo.github.io/badminton-app/
```

---

## 機能一覧

画面は3つのタブに分かれています。

| タブ | 用途 |
|------|------|
| **メンバー** | 登録簿。過去の参加者も含めた全メンバーを登録しておく場所 |
| **試合** | 本日の参加者の休憩切り替え、コート設定、組み合わせの作成・確定 |
| **記録** | その日の試合数、対戦履歴、過去の記録 |

メンバータブで「今回参加する」をONにした人が、試合タブの「本日の参加者」に並びます。そのうち休憩していない人が組み合わせの対象です。

```
登録簿（全メンバー）
  └─ 今回参加する = ON  →  本日の参加者
                              └─ 休憩していない  →  組み合わせの対象
```

### 登録簿
- メンバーの名前を登録・削除
- **性別ボタン**（角丸の四角）：タップするたびに − → M → F → − と切り替わります
  - 男性（M）：青背景 / 女性（F）：ピンク背景
- **レベルボタン**（丸）：タップするたびに − → 1 → 2 → 3 → 4 → 5 → − と切り替わります
  - **5が一番上手い**人。背景色は性別に合わせて変わります
  - 形が違うのは見分けるためです（どちらも未設定だと「−」が並ぶため）
  - レベルは「バランス型」「同レベル」で使います。付けていなければ組み合わせは今までどおりです
- 「今回参加する」スイッチで当日の参加をON/OFF

### 本日の参加者（試合タブ）
- 参加ONのメンバーを名前チップで一覧表示
- **チップをタップするたびに休憩のON/OFFが切り替わります**（休憩中は打ち消し線）
- 休憩中の人は組み合わせの対象から外れます
- 試合中に何度も使う操作なので、組み合わせを作る画面と同じタブに置いています

### 設定・実行
- **コート数**：＋/−ボタンで調整（参加人数に応じて自動制限）
- **コート別シングル/ダブルス**：コートごとに種別を個別設定（デフォルト：ダブルス）
- **組み合わせ優先**：**性別と実力を別々に指定できます**（同時に指定できます）

| 行 | 選択肢 | 内容 |
|---|---|---|
| **性別の希望** | 指定なし | 性別を見ません |
| | 男女ペア | 男女のペアを優先します（ダブルスのみ有効） |
| **実力の希望** | 指定なし | レベルを見ません |
| | **バランス型** | 上手い人と上手くない人を組ませ、対戦する2ペアの強さを揃えます |
| | **同レベル** | 近い強さの人だけでコートを作ります（**2コート以上で効果があります**） |

いま選んでいる内容の説明が、ボタンの下に1行表示されます。設定が効かない状態（1コートで「同レベル」）や、レベルの付け忘れがあるときは、オレンジ色で知らせます。

> **レベルは全員に付けないと狙いどおりに組まれません。** 付いていない人は真ん中（3）として計算されます。全員が未設定なら、結果は「指定なし」と同じになります。

- 上記の設定（コート数・種別・性別と実力の希望）はアプリを閉じても保存されます

### 対戦表
- コートごとに対戦カードを表示（ダブルス：ペアvsペア / シングル：1vs1）
- プレイヤー名に性別カラーを表示
- **待機**（コートに入れなかった人）・**希望休憩**を一覧表示

### 記録のしかた（確定 / 取り消し）

組み合わせを「作った」だけでは記録されません。実際に試合をしたときだけ記録します。

画面で一番大きなボタンは、常に「次にすべきこと」を示します。試合が終わったらこのボタンを押すだけで、**記録と次の組み合わせ作成が同時に行われます**。

| 状態 | 大きいボタン | 小さいボタン |
|------|------|------|
| 組み合わせなし | **組み合わせ作成**（オレンジ） | — |
| 組み合わせ表示中 | **確定して次の組み合わせへ**（緑） | 引き直す / 取り消し |

| 操作 | 動作 |
|------|------|
| **組み合わせ作成** | 組み合わせを表示する（記録されない） |
| **確定して次の組み合わせへ** | 表示中の試合を記録し、続けて次の組み合わせを出す |
| **引き直す** | 記録せずに同じラウンドを引き直す（何度でも可） |
| **取り消し** | 試合をしなかったものとして破棄する |

大きいボタンを押し続けるだけで正しく記録が貯まります。記録したくない場合だけ、小さいボタンを選びます。参加人数が足りず次を作れないときは、ボタンが「確定する」に変わり記録だけを行います。

### 記録タブ
- **今日の試合数**：メンバーごとの試合数。最少の人はオレンジ色で表示
- **今日の対戦履歴**：確定した対戦の一覧。間違って確定したものは削除できます
- **過去の記録**：過去の練習会の一覧（直近100回分を保持）。**日付をタップすると、その日の試合数と全対戦カードを表示します**
- **書き出し**：全記録をJSONファイルとして保存
  - **メンバーの性別とレベルも含まれます。** レベルは主観的な評価なので、ファイルを他の人に渡すときは中身を確認してください
- **改修履歴**：アプリの更新内容の一覧。バージョンをタップすると変更点を表示します。画面上部にも現在のバージョンを表示しているので、更新が実際に届いたかどうかを確認できます

### 公平性と組み合わせの多様性

**誰が出るか**は、**その人がいた間の取り分に対して、どれだけ足りていないか**で決まります（同点の人はランダム）。確率ではなく実数で決めるため、同じ人が続けて待機し続けることがありません。**レベルや性別はここに一切影響しません。** 上手い・下手で待機が偏ることはありません。

**途中から参加した人も、その時点から公平に扱われます。** いなかった間の試合は数えないため、遅れて来た人がコートを独占することはありません。

**休憩から戻った人は、戻って最初の1回だけ優先して出場します。** そのあとは普通に並ぶため、休んだ分をまとめて取り返すことはありません。

**どう組むか**は、その日すでに組んだペア・対戦した相手を避けるように選ばれます。特に**その日まだ一度も組んでいない相手が優先されます**。希望（性別・実力）を設定している場合はそちらが優先され、重複回避は同点時の判断に使われます。

集計はその日のセッションのみが対象です。日付が変わると自動的に新しいセッションが始まるため、メンバーの違う過去の練習会と混ざりません。

## スマホへのインストール方法

### iPhone（Safari必須）

1. **Safari** でアプリURLを開く
2. 画面下部の**共有ボタン**（↑アイコン）をタップ
3. **「ホーム画面に追加」** をタップ
4. **「追加」** をタップして完了

### Android（Chrome）

1. **Chrome** でアプリURLを開く
2. 右上の **「⋮」メニュー** をタップ
3. **「ホーム画面に追加」** または **「アプリをインストール」** をタップ
4. **「インストール」** をタップして完了

> インストール後はホーム画面のアイコンから起動できます。  
> 一度読み込まれた後はオフライン（圏外）でも動作します。

## バージョン更新時（既にインストール済みの場合）

**特別な操作は不要です。** アプリを開くと裏で新しい版を取得し、**次に開いたときから反映されます**。

つまり「一度開いて閉じ、もう一度開く」だけで最新になります（ネット接続が必要）。更新がないときは何も起きません。

> 以前は更新が届かないことがありましたが、キャッシュの方式を変更して解消しています。

## 開発者向け：ローカル環境セットアップ

### 前提条件
- Git がインストールされていること
- テキストエディタ（VSCode推奨）

### セットアップ手順

```bash
# リポジトリをクローン
git clone https://github.com/ko-zo/badminton-app.git

# フォルダを開く
cd badminton-app
```

### 編集からデプロイまでの流れ

```bash
# ファイルを編集後、変更をコミット
git add .
git commit -m "変更内容の説明"

# GitHubへプッシュ（数分後にGitHub Pagesへ自動反映）
git push
```

### 技術スタック

| 項目 | 内容 |
|------|------|
| フロントエンド | HTML / CSS / JavaScript（バニラJS） |
| ホスティング | GitHub Pages |
| PWA | manifest.json + Service Worker |
| データ保存 | localStorage |
| 外部依存 | なし（ライブラリ不使用） |

### ファイル構成

```
├── index.html        # メイン画面
├── app.js            # アプリロジック
├── style.css         # スタイルシート
├── manifest.json     # PWA設定
├── sw.js             # Service Worker（オフライン対応）
├── icons/            # アプリアイコン
│   ├── icon-192.svg
│   ├── icon-512.svg
│   └── icon-maskable.svg
├── docs/             # 設計書・決定記録・要件定義
└── tools/            # 組み合わせの検証スクリプト（アプリ本体には含まれない）
    ├── 実装の検証.js         # app.js を実際に動かして効果と公平性を確認する
    ├── 参加者構成の検証.js    # 自分のクラブの人数・男女比で結果を確かめる
    ├── 組み合わせ検証.js      # レベルの段階数や重みを決めるためのシミュレーション
    └── 基準の干渉検証.js      # 性別と実力の希望が干渉しないかの検証
```

### 組み合わせのアルゴリズムを変更するときは

**この処理は、間違っていても画面上は正常に見えます。** 組み合わせは必ず表示されるため、目視では判断できません。変更したら必ず数値で確認してください。

```bash
node tools/実装の検証.js
```

12人・20ラウンドを100回まわし、対戦の釣り合い・コート内の揃い・男女ペア率・ペアの多様性・試合数の公平性を測って合否を出します。
