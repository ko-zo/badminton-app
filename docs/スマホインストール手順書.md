# バドミントン組み合わせアプリ　スマホインストール手順書

## アプリURL

```
https://ko-zo.github.io/badminton-app/
```

---

## 初めてインストールする場合

### iPhone（Safari必須）

1. **Safari** でアプリURLを開く（Chromeでは追加できません）
2. 画面下部の**共有ボタン**（四角から矢印が出るアイコン）をタップ
3. **「ホーム画面に追加」** をタップ
4. 名前を確認して **「追加」** をタップ
5. ホーム画面にアイコンが表示されれば完了

### Android（Chrome）

1. **Chrome** でアプリURLを開く
2. 右上の **「⋮」メニュー** をタップ
3. **「ホーム画面に追加」** または **「アプリをインストール」** をタップ
4. **「インストール」** をタップ
5. ホーム画面にアイコンが表示されれば完了

## すでにインストール済みの場合（バージョン更新）

アプリの中身が更新されても、スマホには古いバージョンがキャッシュされています。  
以下の手順で最新バージョンに更新してください。

### iPhone

1. ホーム画面のアイコンからアプリを開く
2. アプリが読み込まれるまで少し待つ（バックグラウンドで新バージョンを取得します）
3. アプリを完全に閉じる（画面下からスワイプしてアプリ一覧を出し、アプリを上にスワイプして終了）
4. ホーム画面のアイコンから再度アプリを開く → 新バージョンが反映されます

> **上記で更新されない場合：**
> 1. Safariでアプリ URLを開く
> 2. アドレスバー横の「ぁあ」または「AA」をタップ
> 3. **「Webサイトの設定」→「詳細な Web サイトのデータを削除」** を実行
> 4. Safari を閉じてから、ホーム画面のアイコンで再度開く

### Android

1. ホーム画面のアイコンからアプリを開く
2. 右上の「⋮」メニュー → **「更新」** が表示された場合はタップ
3. 表示されない場合は、アプリを閉じて再度開く

> **上記で更新されない場合：**
> 1. Chromeでアプリ URLを開く
> 2. 右上の「⋮」→ **「設定」→「プライバシーとセキュリティ」→「閲覧データを削除」**
> 3. 「キャッシュされた画像とファイル」にチェックを入れて削除
> 4. アプリを再度開く

---

## オフラインでの利用

一度アクセスして読み込まれた後は、**インターネット未接続でも動作します**。  
ただし、初回アクセスと更新時はネット接続が必要です。

---

## QRコード（インストール用）

スマホのカメラでQRコードを読み取ると、アプリURLを開けます。

※ QRコード画像は別途作成・印刷して配布してください。  
　生成サービス例：[QRのススメ](https://qr.quel.jp/) などで上記URLを入力
