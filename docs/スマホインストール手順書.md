# バドミントン組み合わせアプリ　スマホインストール手順書

## アプリURL

```
https://ko-zo.github.io/badminton-app/
```

---

## 初めてインストールする場合

### iPhone（Safari必須）

1. **Safari** でアプリURLを開く（Chromeでは追加できません）
2. 画面下部の**共有ボタン**（四角から矢印が出るアイコン）をタップ
3. **「ホーム画面に追加」** をタップ
4. 名前を確認して **「追加」** をタップ
5. ホーム画面にアイコンが表示されれば完了

### Android（Chrome）

1. **Chrome** でアプリURLを開く
2. 右上の **「⋮」メニュー** をタップ
3. **「ホーム画面に追加」** または **「アプリをインストール」** をタップ
4. **「インストール」** をタップ
5. ホーム画面にアイコンが表示されれば完了

---

## すでにインストール済みの場合（バージョン更新）

**特別な操作は不要です。** アプリを開いたときに裏で新しいバージョンを取得し、**次に開いたときから反映されます**。

1. ホーム画面のアイコンからアプリを開く（ネット接続が必要）
2. そのまま閉じる
3. もう一度開く → 最新バージョンになっています

iPhone・Android とも同じです。更新がないときは何も起こりません。

> **万一おかしくなった場合（通常は不要です）**
>
> **iPhone：** Safariでアプリ URLを開き、アドレスバー横の「ぁあ」→「Webサイトの設定」→「詳細な Web サイトのデータを削除」  
> **Android：** Chromeの「⋮」→「設定」→「プライバシーとセキュリティ」→「閲覧データを削除」→「キャッシュされた画像とファイル」
>
> ※ この操作をすると**メンバーと対戦記録も消えます**。事前に記録タブの「記録をファイルに書き出す」で保存してください。

---

## オフラインでの利用

一度アクセスして読み込まれた後は、**インターネット未接続でも動作します**。  
ただし、初回アクセスと更新時はネット接続が必要です。

---

## QRコード（インストール用）

スマホのカメラでQRコードを読み取ると、アプリURLを開けます。

※ QRコード画像は別途作成・印刷して配布してください。  
　生成サービス例：[QRのススメ](https://qr.quel.jp/) などで上記URLを入力
